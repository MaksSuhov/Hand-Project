# Документация проекта

**Цель:** любой новый сеанс (человек или агент) восстанавливает полный контекст за минуту — без чтения всего кода. Это экономит токены и время.

## Файлы

| Файл | Что содержит | Обновлять когда |
|---|---|---|
| `PRD.md` | Что за продукт, для кого, требования, чего НЕ делаем | Меняется замысел или объём проекта |
| `ARCHITECTURE.md` | Стек, карта файлов/модулей, ключевые потоки данных, запуск | Меняется структура кода |
| `DECISIONS.md` | ADR: принятые решения + причины (контекст, варианты, выбор) | Принято любое техническое решение |
| `PROGRESS.md` | Сделано / в работе / следующие шаги / проблемы | После каждого значимого шага |

## Правила ведения

- Сжато: факты, списки, ссылки вида `путь/файл:строка`. Без «воды» и без дублирования кода.
- Документируем не *весь* код, а то, что помогает понять проект быстро: зачем, где, почему.
- Обновлять сразу, а не «потом» — устаревшая документация хуже отсутствующей.
- Ориентир: 1–2 экрана на файл. Растёт больше — выносим в отдельный файл (`docs/adr/0001-*.md` и т.п.).

## Для агента

В начале сессии читать: этот файл → `PROGRESS.md` → `ARCHITECTURE.md` → `DECISIONS.md`. Код открывать только по необходимости, точечно.
