# Синтетическая корпоративная база знаний

Вымышленная компания **ООО «Северный Ветер»** (платформа мониторинга «Атлас»). Корпус нужен для проверки RAG и будущих eval-прогонов: в документах есть конкретные числа, сроки, исключения и контакты, которые можно проверять вопросами.

## Как использовать

```bash
.venv/bin/python -m scripts.seed_knowledge          # залить/обновить
.venv/bin/python -m scripts.seed_knowledge --reset  # очистить и залить заново
```

Скрипт режет документы по заголовкам (`MarkdownHeaderTextSplitter`) и размеру (`RecursiveCharacterTextSplitter`), считает эмбеддинги через RouterAI (`baai/bge-m3`, 1024 измерения) и складывает в `knowledge_chunks` (pgvector).

## Для eval

Архивные документы намеренно противоречат действующим: в `99_archive_vacation_2022.md` отпуск 24 дня, в `98_archive_vpn_openvpn.md` — старые правила VPN. Хороший прогон должен проверять, что ассистент отвечает по действующим документам и игнорирует архив.
